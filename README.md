# Alex Styles Portfolio (HTML + CSS project, Copilot-assisted)

## How Copilot assisted each step

- Activity 1 (foundational CSS): Copilot drafted tokens (:root variables), card/grid styles, and button gradients. I tuned colors, radius, and shadow for a polished look.
- Activity 2 (responsive): Copilot suggested breakpoints 900px and 640px plus hamburger nav pattern. I verified: 3-col to 2-col to 1-col, hero stacks, nav collapses.
- Activity 3 (UI/UX + polish): Copilot proposed hover lift/zoom, ::after tooltips from data-tip, and modal quick-view. I added fluid type with clamp(), spacing scale, focus-visible affordances, and consistent shadows.

## Deploy to GitHub Pages

1. New public repo, upload index.html + styles.css (+ script.js), commit Initial commit.
2. Settings > Pages > Deploy from branch > main > Save.
3. Open https://USERNAME.github.io/REPO/.
